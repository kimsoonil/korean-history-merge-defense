## 게임 소개

`한국사 조합 디펜스`는 무작위로 모집한 기본 병사를 조합해 역사 영웅을 만들고, 순환하는 적군을 막아내는 웹게임입니다. 프롤로그의 현대인 플레이어가 신비한 서책 **천명도첩**을 통해 과거의 전장으로 이동하며 이야기가 시작됩니다.

- PC와 모바일 반응형 UI
- Google·Apple 로그인 또는 게스트 플레이
- 브라우저 자동 저장과 이어하기
- 일반·하드 난이도 및 순차 스테이지 개방
- SD 영웅·적군, 전장별 지도와 보스 연출

## 게임 진행

```text
병력 모집 → 전장 배치 → 재료 유닛 수집 → 영웅 조합
     ↓                                      ↓
병력패 소비                         강화·가방·자리 교환
     └────────────── 적 웨이브와 보스 방어 ──────────────┘
```

| 단계 | 플레이 |
|---|---|
| 1. 이야기 선택 | 책장을 넘기며 역사적 전투를 선택합니다. 이전 이야기를 완료하면 다음 이야기가 열립니다. |
| 2. 스테이지 선택 | 지역 지도에서 전선을 고르고 일반 또는 하드 난이도로 입장합니다. |
| 3. 병력 모집 | 병력패를 사용해 1단계 병사를 무작위로 모집합니다. |
| 4. 영웅 조합 | 조합서의 재료를 모아 2~5단계 영웅을 만듭니다. 가방 속 유닛도 재료로 사용할 수 있습니다. |
| 5. 전투와 강화 | 적을 처치해 골드를 얻고 단계·직업·개별 영웅의 공격력을 강화합니다. |
| 6. 보스 격파 | 제한 시간 안에 보스를 처치하고 다음 스테이지와 이야기를 개방합니다. |

## 핵심 시스템

### 모집과 조합

- 기본 병종: 창병, 활병, 수병, 포수, 의병, 기병, 유생
- 시민: 보스 보상으로 획득하며 모든 1단계 조합 재료를 대신할 수 있습니다.
- 조합 가능한 영웅 카드는 테두리가 강조되며, 카드를 누르면 즉시 조합합니다.
- 5단계 영웅 조합 시 전용 일러스트와 대사가 전장 전체에 나타납니다.

### 전장과 라운드

- 적군은 전장 외곽의 길을 계속 순환하고, 영웅은 사거리 안의 적을 자동 공격합니다.
- 한 라운드의 기본 제한 시간은 30초이며 시간이 끝나면 다음 라운드가 시작됩니다.
- 적군이 100명 누적되거나 보스를 90초 안에 처치하지 못하면 패배합니다.
- 보스 라운드에는 전용 체력 표시, 대사, 보상 유닛과 병력패가 제공됩니다.
- 전장 유닛은 최대 25명까지 배치하며 남는 유닛은 가방에 보관할 수 있습니다.

### 성장과 선택

- 단계별 강화, 직업별 강화, 7단계 개별 영웅 강화
- 골드 도박과 1~3단계 유닛 도박
- 전열·수군·책략·지원·기동·수성·군주 등 역할별 능력
- 공격속도·공격력 버프, 스턴, 이동속도 감소와 중첩 방어도 감소
- 하드 모드에서는 일부 5단계 영웅 조합이 제한되며 전용 최초 클리어 보상이 제공됩니다.

## 저장과 로그인

- 게스트와 각 Google·Apple 계정은 같은 브라우저 안에서도 서로 분리된 저장 슬롯을 사용합니다.
- 새로고침하거나 같은 계정으로 다시 로그인하면 해당 계정의 마지막 진행 상황을 자동으로 이어갑니다.
- 기존 공용 브라우저 저장 기록은 게스트 슬롯으로만 이전되며 SNS 계정에는 복사되지 않습니다.
- 현재 저장 파일은 브라우저 내부에 보관됩니다. 브라우저 데이터를 삭제하거나 다른 기기로 이동하면 복구되지 않으며, 기기 간 클라우드 동기화는 별도 구현 대상입니다.

## 로컬 실행

Node.js 20 이상이 필요합니다.

```bash
git clone https://github.com/kimsoonil/korean-history-merge-defense.git
cd korean-history-merge-defense
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

```bash
# 타입 검사
npm run lint

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm start

# 전체 테스트
node --test tests/*.test.mjs
```

## SNS 로그인 설정

`.env.example`을 참고해 `.env.local`을 만듭니다.

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=YOUR_SUPABASE_PUBLISHABLE_KEY
```

Supabase에서 Google·Apple 공급자를 활성화하고 다음 주소를 허용합니다.

```text
http://localhost:3000/**
https://korean-history-merge-defense.slskdkfdl12.chatgpt.site/**
```

실제 비밀키와 `.env.local`은 저장소에 커밋하지 않습니다.
