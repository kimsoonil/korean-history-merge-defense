# 살수 — 한국사 조합 디펜스

Next.js + React + TypeScript로 만든 단일 플레이어 웹게임입니다. 7종의 1단계 병종을 랜덤 소환하고, 조합서에 따라 2~5단계 영웅을 만들어 수나라 침공 1-1부터 살수대첩 1-8까지 방어합니다.

## 실행

Node.js 20 이상에서:

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 배포용 확인은 `npm run build`, 실행은 `npm start`입니다.

## 플레이

- 초기 화면: 「한국사 조합 디펜스」 제목, 제1장 소개, 새로하기·이어하기·영웅 도감·조합서가 표시됩니다. 도감과 조합서는 게임을 시작하기 전에도 볼 수 있습니다. 초기 화면의 조합서는 재료를 소비하지 않는 열람 모드입니다.
- 새로하기 → 스테이지 지도: 바다·숲·성곽이 있는 가로 지도의 1~10번 지점을 점선으로 연결했습니다. 마우스 휠, 가로 스크롤, 드래그, 하단 좌우 버튼으로 이동합니다. 키보드로 지도에 초점을 두고 좌우 화살표 또는 Home/End를 눌러도 탐색할 수 있습니다.
- 1번 지점: 1-1~1-8 전투 선택 팝업이 열립니다. 1-1~1-7은 「수나라의 침공」, 1-8은 「살수대첩」입니다. 첫 게임에는 1-1만 활성화되고, 이전 전투를 클리어해야 다음 전투를 선택할 수 있습니다. 완료된 전투는 다시 선택할 수 있습니다.
- 스테이지 개방 기록: `salsu-campaign-v1`에 별도로 저장하여 새로하기와 새로고침 후에도 유지합니다. 시간 종료 후 전멸하거나 전멸 후 시간 스킵을 선택했을 때 클리어로 인정하며, 미완료 전투를 떠나는 것만으로는 다음 전투가 열리지 않습니다. 2~10번 지점은 준비 중 안내만 표시되고 플레이되지 않습니다.
- 새 전투 시작: 전투 목록에서 선택하고 「전투 준비」를 누르면 320골드·하트 10개로 시작합니다. 진행 중인 저장 기록이 있으면 교체 전에 확인창을 표시합니다. 지도 탐색·팝업 닫기·취소만으로 기록을 덮어쓰지 않습니다. 이어하기는 기존 병력과 자원을 그대로 복원합니다. 기록이 없거나 방어전이 끝났다면 이어하기는 비활성화됩니다.
- 자동 저장 / 이어하기: 같은 브라우저·같은 주소의 로컬 저장 공간(`salsu-progress-v1`)에 유닛 배치·골드·하트·스테이지·남은 시간·속도·적 체력과 위치·출현 수를 저장합니다. 자원 변경 시와 전투 중 1초 간격, 페이지를 떠날 때 저장하며, 예기치 않은 강제 종료 시 마지막 약 1초의 진행은 반영되지 않을 수 있습니다. 새로고침하면 초기 화면으로 돌아오고 이어하기로 복원합니다. 앱을 닫거나 초기 화면에 머문 시간은 전투 시간에서 차감하지 않습니다. 브라우저 데이터를 지우거나 주소/브라우저를 바꾸면 해당 기록을 불러올 수 없습니다.
- 전투 중 오른쪽 위 집 아이콘: 현재 진행을 저장하고 초기 화면으로 돌아갑니다. 초기 화면에서는 전투가 멈춥니다. 저장 공간을 사용할 수 없는 환경은 안내 문구가 표시되고 현재 창에서만 이어하기가 가능합니다.
- 영웅 도감: 오른쪽 위 「도감」 버튼으로 5단계 영웅 8명의 상징 배경·SD 캐릭터·대사를 볼 수 있습니다. 영웅 버튼 또는 이전·다음으로 이동하고 닫기 또는 Esc로 닫습니다. 보유 여부와 관계없이 모두 열람할 수 있으며 유닛·골드·선택 유닛을 변경하지 않습니다. 열람 중에는 전투와 남은 시간이 멈추고, 닫으면 이어집니다. 도감은 자동으로 뜨거나 닫히지 않으며, 게임을 새로고침하기 전까지 마지막으로 본 영웅을 기억합니다. 이전 임시 이미지 테스트 창은 정식 도감으로 전환했습니다.
- 배경음악: 초기 화면·전투 준비·일반 전투는 무음이며, 수양제가 살아 있는 보스전에서만 「살수 결전」을 재생합니다. 보스를 처치하거나 전투를 종료하거나 초기 화면으로 돌아오면 정지합니다. 오른쪽 위 BGM 버튼과 슬라이더로 보스곡의 켜기·끄기·음량을 설정합니다. 설정은 저장되며 기본 음량은 30%입니다. 다른 탭으로 이동하면 음악을 잠시 멈춥니다. 영웅의 대사 목소리는 재생하지 않습니다.
- 병종 소환: 35골드, 7종 중 무작위. 최대 40칸.
- 하단 책 아이콘 조합서: 팝업의 2~5단계 탭에서 보유 재료와 조합 가능 여부를 확인합니다. 조합 시 재료 유닛이 소모됩니다.
- 5단계 조합 성공: 전장 전체에 영웅의 상징 배경, SD 캐릭터, 대사가 나타납니다. 배경은 80% 농도(불투명도 80%, 투명도 20%)로 표시하고 캐릭터와 자막은 선명하게 유지됩니다. 배경이 보이지 않는 문제를 수정하여 배경 → 명암 효과 → SD 영웅 → 제목·자막 순서로 쌓습니다. 세종대왕은 훈민정음과 한글, 이순신은 거북선과 바다를 사용하며 나머지 여섯 영웅도 전용 배경이 있습니다.
- 등장 연출 중에는 적 이동·공격·출현·30초 제한 시간이 일시 정지되고, 종료 후 이어집니다. 건너뛰기 또는 Esc로 닫을 수 있습니다. 움직임 줄이기 설정에서는 등장 애니메이션을 끕니다.
- 조합서 → 5단계 → 각 영웅 카드의 ▶ 버튼으로 재료 소비 없이 등장 연출을 미리 봅니다.
- 등장 연출은 음성 없이 이미지와 대사 자막만 표시합니다.
- 유닛 클릭: 초상화 슬롯, 능력치, 스킬 및 판매 금액 확인. 빈 칸 클릭으로 선택 유닛 이동, 다른 유닛 칸 클릭으로 선택 변경.
- 숲 전장: 적은 숲 공터를 둘러싼 사각 흙길을 순환합니다. 빈 배치칸은 평소 숨겨지고, 유닛을 선택했을 때 이동 가능한 칸이 강조됩니다.
- PC 화면: 왼쪽 전황판에서 현재 스테이지, 남은 시간, 전장에 남은 적군 수, 하트, 골드, 속도를 확인합니다. 오른쪽에는 선택 유닛 정보가 나타나고 중앙 전장을 크게 표시합니다. 모바일은 전장 제목 옆에 시간을 표시합니다.
- 전투 시작: 각 스테이지는 실제 시간 30초 카운트다운으로 진행합니다. 적은 사각 흙길을 계속 순환하며 유닛이 사거리 내 적을 자동 공격합니다. 한 바퀴를 돌았다는 이유로 피해를 주지 않습니다. 30초가 지나도 적이 남으면 연장전이 계속되고, 모든 적을 처치해야 다음 스테이지 버튼이 활성화됩니다. 속도 배율은 전투에만 적용되고 30초 카운트다운에는 영향을 주지 않습니다.
- 시간 스킵: 이번 스테이지의 적이 모두 출현하고 전멸했는데 시간이 남으면 「스킵 · 다음 스테이지」가 활성화됩니다. 누르면 기존 클리어 보상을 한 번 받고 다음 스테이지를 즉시 시작합니다. 적이 잠시 없더라도 아직 출현할 적이 남아 있으면 스킵할 수 없습니다. 1-8은 수양제와 모든 적을 처치한 뒤 「스킵 · 결과 보기」로 최종 승리 팝업을 바로 열 수 있습니다.
- 수나라 적군 6종과 수양제는 `public/portraits/sui-enemies-atlas.png`의 SD 캐릭터로 표시됩니다. 각 초상화는 시트의 한 칸만 보이도록 잘라 전장에 배치됩니다.
- 적군이 이동하는 동안 SD 캐릭터가 가볍게 위아래로 들썩이며, 수양제는 더 느리고 묵직한 리듬으로 움직입니다. 이 모션은 이동 속도나 판정에 영향을 주지 않고, 움직임 줄이기 설정에서는 꺼집니다.
- 공격 시 유닛에서 적에게 짧은 빛줄기가 지나가고 피격 지점에 작은 섬광이 나타납니다. 전투 수치에는 영향을 주지 않으며, 움직임 줄이기 설정에서는 효과를 숨깁니다.
- 1-7에서 다음 전투로 진행하면 1-8 보스 수양제가 전장에 먼저 배치되고 최종전이 자동으로 시작됩니다. 지도에서 개방된 1-8을 새로 선택한 경우에는 준비 화면의 「전투 시작」을 눌러 출현시킵니다. 보스 이름과 체력 막대가 전장에 표시됩니다. 수양제 체력은 1-8 일반 적 최대 체력의 10배(4,890)입니다. 을지문덕은 해당 결전에서 추가 피해를 줍니다.
- 1-1~1-7는 모든 적을 처치한 뒤 남은 시간을 스킵하거나, 30초 종료를 기다려 다음 스테이지 버튼을 눌러 진행합니다. 두 방식 모두 같은 보급 골드를 한 번 받습니다. 중간 클리어 팝업은 뜨지 않고 1-8을 마치면 제1장 최종 승리 팝업이 열립니다. 모든 적을 처치해야 진행하므로 이전의 스테이지 간 잔류 적·두 스테이지 후 하트 감소 규칙은 더 이상 적용되지 않습니다.

기존 10개 전투 저장 기록은 새 8개 전투 구성으로 자동 변환합니다. 기존 1-1~1-7은 그대로 이어지고, 기존 1-8/1-9는 병력·골드를 유지한 채 새 1-8 준비 상태로 이동합니다. 기존 1-10 보스전은 적 체력·위치·남은 시간을 그대로 유지하여 새 1-8로 이어집니다.\n\n## 아트 슬롯

기존 일반곡 `public/audio/forest-calm.wav`는 보관용으로 남겨두었으며 게임에서는 재생하지 않습니다. 제작 정보와 현재 재생 방식은 `docs/music.md`, 재생성 스크립트는 `scripts/render-bgm.mjs`에 있습니다.

수양제가 등장하면 빠르고 긴박한 전용곡 `public/audio/salsu-boss.wav`(25.6초·150 BPM)을 재생합니다. 보스 처치나 게임 종료 후에는 무음이며, BGM 켜기·끄기 및 음량 설정은 그대로 유지됩니다. 기존 보스 음원은 변경하지 않았습니다. 보스곡 재생성은 `node scripts/render-bgm.mjs --boss`입니다.

1단계 7종(창병, 활병, 수병, 포수, 의병, 기병, 유생)은 개별 투명 배경 SD 캐릭터 이미지를 적용했습니다. 2~5단계 영웅 32명은 단계별 4×2 캐릭터 시트(`public/portraits/tier-2-atlas.png`부터 `tier-5-atlas.png`)에 담았고, 각 영웅의 위치를 `lib/game.ts`에서 연결합니다. 초상화는 유닛 칸, 정보 패널, 조합서에 공통으로 표시됩니다.

전장 숲 바닥 그림은 `public/terrain/forest-ground.png`입니다. 원본 참고 이미지의 UI나 캐릭터를 복제하지 않은 독자적인 환경 이미지이며, 흙길과 배치칸은 화면 크기에 따라 CSS로 그려집니다.

5단계 전용 상징 배경 8장은 `public/cinematics/`에 있고, 대사·상징은 `lib/legendary.ts`에서 관리합니다. 내장 이미지 생성 도구로 제작한 최종 프롬프트와 대사 출처는 `docs/legendary-art.md`에 기록했습니다. 세종대왕과 이순신 이외의 대사는 게임 창작 대사임을 연출 화면에 명시합니다.

조합식·스탯·스킬은 `lib/game.ts`에서 편집할 수 있습니다. 조합식은 역사적 친족 관계가 아니라 게임적 상징과 병종의 연결이며, 이전 대화에서 명시된 2~4단계와 이순신 조합을 반영했습니다. 명시되지 않은 다른 5단계 조합은 플레이 가능한 초안으로 구성했습니다.
