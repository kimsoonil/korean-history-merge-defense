# 향후 7단계 확장 및 이야기 최종전 밸런스 아이디어

> 상태: 기획안. 현재 게임 코드에는 적용하지 않는다.

## 1. 4~7단계 전투력 기준

- 1~3단계는 현재 수치를 유지한다.
- 역할 효과, 적 방어도, 강화, 주변 버프, 액티브 스킬을 제외한 평균 역할 적용 DPS 목표는 다음과 같다.

| 단계 | 평균 역할 적용 DPS | 5단계 대비 |
| --- | ---: | ---: |
| 3단계 | 약 150 | 0.31배 |
| 4단계 | 약 260 | 0.54배 |
| 5단계 | 약 480 | 1.00배 |
| 6단계 | 약 1,020 | 2.13배 |
| 7단계 | 약 1,960 | 4.08배 |

- 6~7단계의 역할 버프와 방어도 감소 수치는 5단계 수치에서 더 증가시키지 않는다.
- 높은 단계의 성장은 기본 공격력, 공격속도, 고유 스킬로 만든다.
- 최종 목표는 하드 노량해전 10스테이지를 7단계 영웅 약 3명의 무력 조합 또는 7단계 1명과 5~6단계 방어도 감소·지원·제어 조합으로 클리어하는 것이다.

## 2. 일반 모드 이야기 최종전 원군

- 각 이야기의 일반 10스테이지 최종 보스는 하드와 같은 체력과 방어도를 사용한다.
- 최종 보스 등장 20초 후 해당 전투의 역사 영웅이 원군으로 등장한다.
- 하드 모드에는 원군과 원군 대사를 적용하지 않는다.
- 원군은 평균 7단계 영웅보다 약 15% 강하지만, 플레이어 강화와 주변 버프를 받지 않는다.
- 원군은 배치 제한에 포함하지 않으며 이동·판매·조합할 수 없다.
- 원군 혼자 보스를 처치할 수 없고, 남은 70초 동안 보스 최대 체력의 약 30~35%를 담당한다.
- 보스 출현, 원군 등장, 보스 체력 50%, 보스 처치 시점에 대화를 나누어 이야기를 진행한다.

| 이야기 | 일반 최종전 원군 |
| --- | --- |
| 살수대첩 | 을지문덕 |
| 안시성 전투 | 양만춘 |
| 황산벌 전투 | 계백 |
| 나당전쟁 | 문무왕 또는 김유신 |
| 귀주대첩 | 강감찬 |
| 처인성 전투 | 김윤후 |
| 한산도대첩 | 이순신 |
| 행주대첩 | 권율 |
| 명량대첩 | 이순신 |
| 노량해전 | 이순신 |

## 3. 적군 난이도 설계안

적군 수치는 `이야기 진행도 × 스테이지 진행도 × 라운드 진행률 × 난이도`로 계산한다.

### 일반 적군

- 이야기 배율: `1 + 0.12 × (이야기 - 1)`
- 스테이지 배율: `1 + 0.10 × (스테이지 - 1)`
- 라운드 진행률: `p = (현재 라운드 - 1) / (최대 라운드 - 1)`
- 라운드 체력 배율: `1 + 3 × p^1.6`
- 하드 체력: `200 × 이야기 배율 × 스테이지 배율 × 라운드 체력 배율`
- 하드 방어도: `8 × (이야기 - 1) + 8 × (스테이지 - 1) + p × (20 + 20 × 스테이지)`

### 일반/하드 보정

- 일반 1~9스테이지: 하드 산출값의 70%
- 일반 10스테이지 일반 적·중간 보스: 하드 산출값의 85%
- 일반 10스테이지 최종 보스: 하드와 100% 동일
- 하드: 산출값 100%, 역사 영웅 원군 없음
- 적 이동속도와 보스 행동 방식은 일반과 하드가 동일하다.

### 보스

- 중간 보스 체력: 같은 라운드 일반 적 체력의 8배
- 중간 보스 방어도: 같은 라운드 일반 적 방어도 +40
- 스테이지 마지막 보스 체력: 마지막 라운드 일반 적 체력 × `(12 + 2 × 스테이지)`
- 스테이지 마지막 보스 방어도: 마지막 라운드 일반 적 방어도 +60
- 이야기 10스테이지 최종 보스 체력은 살수대첩 55,000부터 시작해 이야기마다 5,000씩 증가하고, 노량해전에서 100,000이 된다.
- 이야기 10스테이지 최종 보스 방어도는 첫 이야기 310에서 시작해 이야기마다 10씩 증가하고, 노량해전에서 400이 된다.
- 모든 보스전 제한시간은 90초다.
- 스테이지 마지막 보스는 처치 보상을 지급하지 않는다.

## 4. 목표 플레이 흐름

| 구간 | 요구되는 준비 |
| --- | --- |
| 초반 | 3~4단계 핵심 공격 유닛 확보 |
| 중반 | 첫 5단계와 단계·직업 강화 |
| 중후반 | 6단계 또는 방어도 감소·지원 조합 확보 |
| 후반 | 7단계 핵심 영웅과 역할 조합 완성 |
| 하드 최종전 | 7단계 3명 또는 7단계 1명+5~6단계 시너지 조합 |

- 20라운드에 5단계를 만든 뒤 아무 조작 없이 마지막까지 클리어하는 상황을 막는다.
- 후반으로 갈수록 방어도 증가량이 커져 책략·수군·수성의 방어도 감소가 중요해진다.
- 순수 공격력만 사용하는 조합도 7단계 약 3명을 완성하면 클리어할 수 있게 한다.
