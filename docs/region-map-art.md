# 전용 지역 선택 지도

imagegen 스킬과 내장 image_gen 도구로 새로 생성. 전투용 맵과 표지는 변경하지 않음. 살수대첩은 기존 campaign-panorama.png 유지. 게임용 추상 지형이며 실제 지도를 재현한 것이 아님.

모든 결과: 2172 × 724, 3:1. public/regions 에 원본 PNG 저장. regionMaps로 이야기별 연결하고 ResizeObserver로 원본 비율 유지.
