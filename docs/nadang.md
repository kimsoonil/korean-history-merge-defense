# 나당전쟁 추가 및 이야기 표지 정리

## 플레이

살수대첩 → 안시성 → 황산벌의 일반 10스테이지를 모두 완료하면 제4장 나당전쟁이 열립니다. 각 장의 일반/하드 진도는 별도로 저장됩니다. 나당전쟁 일반 10스테이지 완료 후 해당 장의 하드가 열립니다.

- 1~3: 신라 국경 (670~674년), 육상 맵
- 4~6: 매소성 (675년), 육상 맵
- 7~9: 기벌포 (676년), 연안 맵
- 10: 설인귀 최종전 (676년), 연안 맵

스테이지별 라운드는 20,25,…65. 기존 보스 제한 90초, 일반/하드 인원·보상·강화·조합 금지 규칙을 유지합니다. 마지막 설인귀 체력은 일반 50,000 / 하드 100,000입니다. 적 SD는 기존 병종 아틀라스를 재사용합니다.

## 역사와 각색

670~676년의 나당전쟁, 675년 매소성, 676년 기벌포를 배경으로 합니다. 대사·반복 보스·전선 이동 순서는 게임적 각색이며 실제 인물의 발언이나 전투 재현을 주장하지 않습니다. 해전은 기존 순환 디펜스 규칙의 연안 방어전으로 표현합니다. 김유신을 675~676년의 현장 인물로 등장시키지 않습니다.

참고: [한국민족문화대백과사전 나당전쟁](https://encykorea.aks.ac.kr/Article/E0011307), [매소성전투](https://encykorea.aks.ac.kr/Article/E0017963), [국사편찬위원회 기벌포 기록](https://db.history.go.kr/id/sg_007r_0020_0590).

## 이야기 이미지 점검

| 이야기 | 변경 |
|---|---|
| 살수대첩 | 기존 을지문덕 연출 이미지 유지 |
| 안시성 | 전장 바닥 → 성곽 항전 삽화 |
| 황산벌 | 거대한 마법 검 → 백제·신라 군대가 맞선 들판 |
| 나당전쟁 | 평양성 맵 → 신라 육상·해상 항전 |
| 귀주대첩 | 요동성 맵 → 고려군·거란 기병 전투 |
| 처인성 | 수양제 맵 → 낮은 토성과 승려 궁수 |
| 한산도대첩 | 기존 이순신 함대 이미지 유지 |
| 행주대첩 | 정조·수원 성곽 → 강변 토성·목책 방어 |
| 명량대첩 | 살수 맵 → 조류가 흐르는 해협·판옥선 |
| 남한산성 | 요동성 맵 → 겨울 산성 |
