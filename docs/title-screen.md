# 초기 화면 및 이어하기

## 구성

- 참고 게임의 큰 제목, 챕터 소개, 시작/이어하기 동선을 참고했습니다. 원본 이미지나 소스는 가져오지 않았습니다.
- 기존 정조 연출의 성곽 배경과 세종대왕·이순신·광개토대왕 SD 이미지를 재사용하고, 짙은 숲색·황금색 버튼으로 한국사 테마를 구성했습니다. 배경은 한국사 판타지 연출이며 특정 전투 장소의 고증 이미지가 아닙니다.
- 초기 화면에서 도감 8명과 2~5단계 조합식 32개를 열람할 수 있습니다. 조합서의 ▶ 버튼은 해당 영웅의 도감 이미지로 연결됩니다.
- PC는 제목/메뉴와 영웅 일러스트를 좌우로, 모바일은 주요 버튼을 세로로 배치합니다. 작은 화면의 조합 재료가 잘리지 않도록 제목 줄 높이도 조정했습니다.

## 저장 정책

- `lib/save.ts`의 버전 2 포맷 (버전 1의 기존 10개 전투 기록 자동 변환), 브라우저 `localStorage`의 `salsu-progress-v1` 키를 사용합니다. BGM 설정 키와 분리되어 있습니다.
- 전투 준비/진행/스테이지 완료 상태만 이어할 수 있습니다. 최종 승리 및 패배는 새 게임으로 시작합니다.
- 저장된 유닛명, 칸, 식별자, 자원, 적 체력·위치·소속 스테이지와 상태를 검증합니다. 손상된 기록은 실행하지 않습니다.
- 절대 시각 대신 남은 시간을 저장하므로 게임 밖에서 보낸 시간은 차감되지 않습니다. 도감/등장 연출 중에는 일시 정지 시점을 기준으로 저장합니다.
- 복원 시 현재 식별자 최댓값 다음부터 새 유닛을 생성하고, 이미 완료한 스테이지의 보상 지급 상태도 복원합니다.
- 새로하기는 스테이지 지도를 열며, 선택한 전투에서 새 게임으로 저장 기록을 교체하기 전에 확인창을 제공합니다. 스테이지 개방 기록은 별도 저장합니다. 초기 화면에서 단순히 도감이나 조합서를 열어도 저장 기록은 바뀌지 않습니다.
- 저장 공간을 사용할 수 없으면 경고를 표시합니다. 이 경우 같은 창의 메모리 기록만 사용할 수 있습니다. 클라우드 동기화나 여러 탭의 동시 플레이 조정은 포함하지 않습니다.

## 검증 (2026-09-20)

- `npm run build`, TypeScript 검사 통과.
- Node.js 22 이상에서 `node --test tests/*.test.mjs`: 20개 통과. 저장/복원, 시간 일시 정지, 완료 보상 상태, 보스 상태, 잘못된 기록 거부를 포함합니다.
- 실제 브라우저에서 시작 전 도감/조합서, 5단계 도감 연결, 새 게임 확인/취소, 320골드·하트 10개 초기화 확인.
- 병종 5명을 소환한 뒤 145골드와 유닛 5명의 종류·배치가 새로고침 후 동일하게 복원됨을 확인.
- 적 7명이 출현한 전투에서 초기 화면으로 나간 뒤 새로고침/이어하기 시 적 체력과 남은 시간이 유지됨을 확인.
- 1280×720, 390×844, 320×568의 초기 화면과 844×390 가로 배치 확인. 320×568에서 2~5단계 모든 조합 재료 영역의 잘림이 없음을 확인.

현재 수정본 로컬 주소: `http://localhost:3101/` (3100은 기존 실행 프로세스가 사용 중).
