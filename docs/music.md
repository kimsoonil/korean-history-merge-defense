# 배경음악 — 보스전 전용

초기 화면, 도감, 전투 준비, 일반 스테이지에서는 배경음악을 재생하지 않습니다. 수양제가 살아 있는 보스전에서만 기존 보스곡을 재생하며, 보스 처치·전투 종료·초기 화면 복귀 시 즉시 멈춥니다. BGM 버튼과 음량 슬라이더는 보스전용 재생 설정입니다.

## 보관 음원: 고요한 숲길 (게임에서 재생하지 않음)

- 파일: `public/audio/forest-calm.wav` (이전 곡과 경로를 분리해 브라우저 캐시가 남지 않도록 교체)
- 길이: 40초, 96 BPM, 16마디, 반복 재생
- 형식: 24 kHz / 16-bit PCM / stereo WAV
- 구성: 따뜻한 다장조의 8마디 반복 선율, 부드러운 전자피아노 계열 합성 음색과 천천히 이어지는 반주. 통통 튀던 짧은 타건음·엇박 반주·드럼·셰이커를 없애고, 음의 시작과 잔향을 부드럽게 만들었습니다. 음표 밀도와 평균 음량을 낮추되 어두운 단조 드론은 사용하지 않습니다.
- 출처: 이 프로젝트를 위해 직접 구성한 선율과 합성 악기. 벤치마킹 사이트의 음원이나 제3자 녹음을 사용하지 않았습니다. 실제 국악기 연주 녹음은 아닙니다.
- 재생성: `node scripts/render-bgm.mjs`

## 보스전: 살수 결전

- 파일: `public/audio/salsu-boss.wav`
- 길이: 25.6초, 150 BPM, 16마디, 반복 재생
- 구성: 빠른 단조 반복구와 짧은 현악 계열 합성 음색, 촘촘한 타악 리듬으로 긴박감을 표현한 자체 제작 음원
- 재생성: `node scripts/render-bgm.mjs --boss`
- 기존 보스곡은 변경하지 않았습니다. 음원 파일의 SHA-256 해시를 테스트하여 보존 여부를 확인합니다.
- 전환: 수양제가 살아 있고 전투 중일 때만 보스 BGM을 재생합니다. 보스 처치·게임 종료·다시 시작 시 음악을 정지합니다. 1-8에 일반 적만 남아 있어도 무음입니다.
- 하나의 오디오 플레이어만 사용하고, 보스전 밖에서는 오디오 소스도 연결하지 않습니다. 화면 클릭·음량 변경·탭 복귀·늦게 완료된 재생 요청 모두 보스전 여부를 확인하여 일반 음악이 다시 켜지지 않게 합니다. 기존 음량과 꺼짐 설정을 유지합니다.

게임을 클릭하거나 키보드 Enter/Space로 조작한 뒤 보스전 진입 시 재생을 요청합니다. 오른쪽 위 BGM 버튼으로 보스전 음악을 켜고 끄고, 옆 슬라이더로 음량을 조절합니다. 보스전이 아닐 때 버튼을 켜거나 음량을 변경해도 음악은 나오지 않습니다. 기본 음량은 30%이며 선택값은 해당 브라우저에 저장됩니다. 페이지를 떠나면 일시 정지하고 돌아오면 보스전 여부와 기존 설정에 따라 재개합니다. 게임 속도를 변경해도 음악 속도는 바뀌지 않으며, 영웅 등장 연출에서도 대사 음성은 재생하지 않습니다.

브라우저의 자동 재생 제한으로 재생이 차단되면 보스전 화면을 클릭하거나 BGM 버튼을 껐다 켜서 다시 요청할 수 있습니다. 음악을 끈 설정은 이후 게임 조작으로 다시 켜지지 않습니다.
